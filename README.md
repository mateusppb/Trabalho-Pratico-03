
# 🎬 Trabalho Prático – Manipulação de Dados Disney+ 📊

---

## 📖 Descrição

Este trabalho prático consiste em programas em Java que lêem um arquivo CSV contendo dados de filmes e séries da plataforma Disney+, e criam diferentes estruturas de dados (listas encadeadas, pilhas, alocação flexível e sequencial) para armazenar e manipular esses registros. O projeto também contempla operações típicas sobre essas estruturas, como inserção, remoção, busca e ordenação.

---

## 🚀 Funcionalidades

- 📂 Leitura do arquivo CSV (`disneyplus.csv`), tratando corretamente campos vazios, aspas internas e vírgulas dentro dos campos.
- 🧩 Implementação de Tipos Abstratos de Dados (TADs) para armazenar objetos do tipo `Show`.
- 🔄 Desenvolvimento de estruturas flexíveis (listas encadeadas, pilhas) e sequenciais para gerenciar os registros.
- ✨ Métodos para inserção e remoção em diferentes posições das estruturas (início, meio, fim).
- 📈 Implementação de algoritmos de ordenação para organizar os dados conforme critérios definidos.
- 💻 Interação via entrada padrão, permitindo comandos dinâmicos para manipular as estruturas e exibir resultados formatados.

---

## 🏗️ Estrutura do projeto

- 🎞️ Classes para representação dos registros (`Show`).
- 🔗 Classes que implementam nós e estruturas (listas, pilhas) com alocação dinâmica e sequencial.
- 🛠️ Métodos de leitura, parsing do CSV, e tratamento dos dados.
- 🎮 Módulo principal para leitura dos comandos, execução das operações e saída dos resultados.

## ⚙️ Como usar

1. Compile todas as classes Java:
   ```bash
   javac *.java
   ```

2. Execute a aplicação redirecionando a entrada com os dados e comandos, por exemplo:
   ```bash
   java Main < entrada.txt
   ```

3. A saída será exibida no console, com os registros removidos e o estado final das estruturas.
